# NetTrainer

Тренажёр сетей в стиле Cisco Packet Tracer с вкладкой **Training**: случайные задания на английском с переводом на русский, автоматическая проверка, подсказки и решение.

## Как открыть

- **Приложение:** https://leonid14022003-eng.github.io/NetTrainer/
  - iPhone: Safari → «Поделиться» → «На экран Домой».
  - Mac: Safari → «Файл» → «Добавить в Dock» (или «Установить» в Chrome).
  - Работает без интернета. Когда выходит новая версия, внизу появляется плашка «Обновить».
- **Файл:** после `python3 build.py` дважды кликните `dist/NetTrainer.html` — всё в одном файле, интернет и сервер не нужны.
- **claude.ai:** та же сборка (`dist/artifact.html`) опубликована как Artifact; только там работают кнопка 🤖 «Объясни» и синхронизация телефона с компьютером.

Прогресс хранится в браузере отдельно для каждого варианта. Перенести его: Learn → кнопка ⇅ (или File → Export / import progress) — Export в одном месте, Import в другом; при импорте прогресс сливается, ничего не теряется.

## Что умеет

- **Logical**: устройства (роутеры 4331/4321/1941/2901/2911, свитчи 2960/2950, хаб, ПК, ноутбук, сервер, принтер), кабели Automatic / Straight-Through / Cross-Over / Console, индикаторы портов, подсказки при наведении.
- **Physical**: стойка и стол в Main Wiring Closet, кабели (цвет, Manage Cable), Inspect Front/Rear, кнопка питания.
- **Окно устройства**: Physical, Config (формы + Equivalent IOS Commands), CLI (эмуляция IOS: сокращения команд, `?`, Tab, `do`, show-команды) и Desktop у ПК (IP Configuration с DHCP, Command Prompt: ping/ipconfig/tracert/arp, Terminal через консольный кабель).
- **Сеть**: VLAN, trunk (DTP), router-on-a-stick, статика, RIP v1/v2, OSPF, DHCP-сервер и relay, ARP, SVI, пароли, баннер, SSH, сохранение конфигурации.
- **STP и EtherChannel** (`js/switching.js`): PVST+ / Rapid PVST+ — выбор корня по Bridge ID, стоимость пути, роли Root / Desg / Altn, блокировка петель (оранжевый индикатор), priority / root primary / secondary, PortFast, BPDU Guard; EtherChannel LACP / PAgP / on с флагами P / I / s / D, Port-channel как один порт для STP, EtherChannel guard. Команды `show spanning-tree [vlan N | summary]`, `show etherchannel summary`.
- **Simulation**: пошаговые пакеты ARP / ICMP / DHCP с анимацией, Event List, PDU Information.
- **Training**: 21 шаблон по 9 темам и 3 уровням сложности. Адреса, VLAN и порты каждый раз генерируются случайно.
- **Файлы и запуск**: каждый запуск — с пустой рабочей области (как в Packet Tracer); прошлая работа — в Open → «Last session (autosave)». Save сохраняет проект прямо в браузере (работает и в онлайн-версии, где скачивание запрещено), а также скачивает файл или копирует текст; Open — из браузера, из файла или из вставленного текста. Иконка печати делает картинку схемы (PNG). Copy/Paste/Undo/Redo серые, когда делать нечего; выделенное устройство обведено пунктиром; Delete удаляет выделенное, иначе включает режим удаления с подсказкой.
- **Наставник в Training**: под каждой красной проверкой — что не так (сейчас X, нужно Y), почему это важно, раскрывающийся блок «Как исправить» с точными командами для этого задания (пояснение к каждой строке на EN/RU/HE) и ссылка на урок. Кнопка **🎓 Example** открывает то же упражнение с другими данными и решает его по шагам на схеме: после каждого шага видно, какие проверки стали зелёными; затем можно вернуться к своему заданию или взять новое похожее.
- **Learn** — полный курс «Сети от А до Я» по программе Cisco NetAcad (ITN → SRWE → ENSA = CCNA 200-301). Текст на английском, перевод на русский и иврит (переключатели RU / HE). Готово: все 17 модулей ITN, из SRWE — VLAN, Inter-VLAN, DHCPv4, статическая маршрутизация, из ENSA — OSPF и поиск неисправностей, плюс RIP. Остальные модули видны на карте курса как «скоро».
  - В конце урока: ключевые термины с озвучкой, вопросы для собеседования по теме, мини-тест (6 вопросов, 70%, часть вопросов генерируется заново), кнопки Practice (задание в симуляторе) и Drill.
  - Итоговый тест каждой части и экзамен по всему курсу.
  - **Drills** — бесконечные тренажёры: двоичная/hex, подсети, IPv6, порты, коммутация и ARP, маршрутизация, wildcard. Клавиши 1–4 и Enter.
  - **Glossary** — 146 терминов на трёх языках, карточки с уровнями запоминания, поиск, озвучка.
  - **Interview** — 37 вопросов с образцовыми ответами на трёх языках и самооценкой.
  - Прогресс и серия дней хранятся в браузере.

## Разработка

```bash
./tests/run.sh       # тесты движка и всех заданий (JavaScriptCore, без Node)
python3 build.py     # dist/NetTrainer.html, dist/artifact.html (claude.ai) и docs/ (приложение)
```

Для разработки можно открыть `index.html` напрямую или через локальный сервер: `python3 -m http.server 8765`.

### Как выпустить обновление приложения

1. `./tests/run.sh` — все тесты зелёные.
2. `python3 build.py` — пересобирает `docs/`; версия приложения — хэш файлов, поэтому меняется только когда что-то изменилось.
3. `git add -A && git commit -m "…" && git push` — GitHub Pages публикует `docs/` из ветки `main` примерно за минуту.
4. Установленное приложение само находит новую версию (при запуске и при возвращении в него) и показывает плашку «Обновить».

- `docs/` создаётся сборкой целиком — руками там ничего не правим.
- `pwa/` — манифест, service worker (`sw.js`, офлайн и обновления) и иконки; `pwa/make_icons.py` перерисовывает иконки (нужен Pillow).
- `js/ui/pwa.js` включается только в сборке `docs/` (там есть `<link rel="manifest">`); в claude.ai и в файле с диска ничего не делает.
- Новые вопросы собеседования (`IV(...)`) получают постоянный id четвёртым аргументом — по id хранятся оценки.
